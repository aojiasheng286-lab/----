多功能调试器 设计思路
STM32F103C8T6 + HAL 库

一、整体思路
主循环只做调度：串口发送、导航键、灯效、页面，一共四行，
每个任务自己判断时间到没到，没到就立刻返回，所以主循环不会被卡住。
三个定时器分开用：TIM4 出 1ms 扫按键，TIM3 出 1kHz 给 LED，TIM2 出 50Hz 给舵机。
舵机不能和 LED 共用一个定时器，因为同一个定时器的通道共用一个频率。

二、按键和灯效
按键挂在 1ms 中断上，连续 20ms 读数一样才算按下，而且只报一次，
按住不放不会重复触发。KEY1/KEY2 还分短按、长按、双击、双键同按。
灯效五种模式，对 LED 出 1kHz PWM，比较值 0~1000 除以 10 就是亮度百分比。

三、串口
接收走中断，回调里必须重新打开接收，不然只收得到第一个字节。
收到换行算一行结束，两个字符以上存成消息；行首是 1~5 或 p 就当命令执行。
发送每 500ms 一帧用 DMA，不能连发两次，第二次会返回 HAL_BUSY。

四、显示和其他
OLED 用显存机制，画完整屏再一起推，所以不闪。
ADC 采 PB1，MPU6050 走 I2C 一次读 14 个字节，舵机用 TIM2 出 50Hz。
